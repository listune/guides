# Web Dashboard

Listune provides a web management interface at [listune.app](https://listune.app). Server owners and administrators can configure server behavior, customize player presentation, inspect analytics, and control live playback directly from any web browser.

## Access and Authentication

1. Navigate to [listune.app](https://listune.app).
2. Click **Login with Discord** in the top navigation bar.
3. Authorize the application via Discord OAuth2.
4. Select the target server from your server selector list. Only servers where you possess the **Manage Server** permission will appear as manageable.

## Dashboard Sections

The server dashboard is organized into four dedicated management areas:

- [Guild Settings](guild-settings.md): Manage general bot settings including prefixes, default search engines, 24/7 mode, DJ roles, and dedicated request channels.
- [Guild Statistics](guild-statistics.md): Track server-wide listening activity, total play counts, and top tracks and artists.
- [Player Control](player-control.md): Customize how the bot player looks and behaves in your Discord channels, including embed styles and button configurations.
- [Custom Bot Profile](custom-profile-bot.md): Customize the bot server-specific nickname, bio, avatar, and banner for your community.
